= Durex
:icons: font

a multi-module Java platform for high quality Spring Boot development

Features:

* DDD, TDD/BDD
* Spring Boot runtime with explicit Durex capabilities
* Shared HTTP service contracts for server/client reuse
* Spring-native Redis Pub/Sub and Stream messaging
* Native deployment with GraalVM
* Json Schema (xref:core/shared/json-schema-annotation/readme.adoc[jsonSchema])
* Messaging (xref:core/shared/messaging/README.md[Spring Messaging])
